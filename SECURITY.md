# Security
This repository is a research foundation and has no supported public release yet.
Do not open a public issue containing exploit details, credentials or private files. If GitHub private vulnerability reporting is enabled, use it; otherwise request a private contact from a maintainer without disclosing sensitive details. A dedicated security address is not configured.
File originals must be preserved. The future receiver must never signal MOVE for conversion input. Treat data objects, paths, virtual files and converter input as untrusted. No network upload of user files, Explorer injection, keylogging or elevated product execution.
Dependencies must be reviewed for vulnerabilities and redistribution obligations before shipping. There is no assertion that an automated scan has already passed.
