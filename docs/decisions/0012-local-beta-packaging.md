# ADR0012 — Candidato local por usuario

Fecha:2026-10-21. El propietario continúa M5 después de aceptar el enlace de conversión. No se autoriza publicación, push o cambios automáticos de startup.

Se elige dotnet publish con .NET10.0.13 y Windows App SDK self-contained, sin trimming, ReadyToRun ni single-file. El payload completo se conserva en una carpeta nueva, acompañado de versión0.1.0-beta.1, source commit/dirty flag, hashes, manual y notices sin modificar. No se elimina un staging fallido ni se reemplaza un artefacto previo. Una carpeta autocontenida se puede ejecutar o incluir en un instalador; no se confunde con una prueba de máquina limpia.

Alternativas: MSIX requiere identidad/firma/trust para instalación externa; las herramientas SDK están disponibles pero no se cambiará el trust del propietario. Un script casero de instalación exige mantener ownership/desinstalación; se prefiere Inno Setup7.1.0 oficial y fijado. Su licencia permite uso según condiciones del texto; se conservan sus avisos. Descarga verificada por hash upstream+hash fijo y Authenticode Pyrsys B.V.; modo portable solo bajo.tools, sin registrar el compilador en Windows. Ayuda instalada corroborada antes de usarlo.

Instalador x64/Windows11/per-user/lowest. No Run, asociaciones, descargas de runtime o lanzamiento automático; solo programa y acceso del menú Inicio. La app conserva un mutex de presencia durante todo su proceso, también en modos diagnósticos. Setup/uninstall detectan ese nombre y se detienen sin cerrar procesos. Se comprueba otra vez antes de instalar; no es un lock transaccional contra un proceso que arranque después. La beta rechaza carpeta con contenido y registro previo de instalación; no hay upgrade in-place, rollback de upgrade ni borrado recursivo personalizado. Desinstalación estándar de archivos conocidos, preservando archivos ajenos/configuración/resultados. Solo elimina un Run exactamente coincidente con el comando de su propio ejecutable, sin garantía de compare-and-swap frente a carreras.

El ensayo usa la misma fuente y payload con AppId/nombre de test y sin acceso del menú Inicio. Así puede instalarse en un directorio privado, comprobar hashes/negativas y desinstalarse sin reemplazar una instalación del propietario. Además se ensayó la identidad normal en otro destino privado: se detiene si hay registro/link previos; verifica el acceso Inicio real y lo retira con el desinstalador. Ambos preservan archivos ajenos/perfil/Run. No equivale a ensayar la ruta predeterminada LocalAppData ni un usuario limpio. Artefacto normal sin firma: preparación local revisable, sin garantía de publisher trust/SmartScreen ni instrucción de bypass. [Evidencia y límites](../reports/m5-local-candidate.md).

CI separa el caso InteractiveShell del conjunto headless mediante trait; el build local por defecto conserva la suite completa. Workflow manual de packaging solo sube artefactos temporales para revisión, no crea releases/tags ni publica automáticamente. No se ejecutará remotamente sin autorización de push; configuración no implica ejecución demostrada.
