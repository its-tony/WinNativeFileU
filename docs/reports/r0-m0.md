## Architecture Decisions

WinUI3/Windows App SDK 2.5.1 estable y .NET10 LTS/SDK 10.0.402; App y Core separados; tests de dominio. Unpackaged x64 con componentes WindowsAppSDK incluidos, .NET10 requerido en runtime. Sin promesa de EXE único ni instalador.

Candidato para M1: HWND propio como IDropTarget con OLE/STA y recepción real de IDataObject. Atajo no equivale a selección; solo COPY/NONE. Alternativas: Shell documentado o armar antes de arrastrar. Sin inyección/hooks globales/keylogging. Combinar APIs para gesto ideal permanece **HYPOTHESIS**. Cerrar nuestro overlay no cancela necesariamente el arrastre del origen.

ADRs: [fundación](../decisions/0001-foundation.md), [receptor OLE](../decisions/0002-drag-overlay.md). Especificación independiente: [functional-specification.md](../functional-specification.md).
