# Code of conduct
Treat contributors respectfully. Discuss technical work with evidence; welcome questions and corrections. Harassment, discrimination, threats and disclosure of private information are unacceptable.
Maintainers may remove harmful content or restrict participation to protect the community. Apply decisions consistently and allow respectful clarification.
Report concerns privately to a maintainer through an available private channel. Do not include personal details in public issues. A dedicated confidential reporting address has not yet been configured.
