# Contributing
Use the pinned SDK on Windows and run scripts/build.ps1 -LockedRestore before submitting changes. Keep PRs limited to one behavior, include actual validation and distinguish automated tests from manual Windows checks.
Use Conventional Commits. Keep UI, Windows integration and domain responsibilities separate. Do not add empty abstractions, heavyweight converters or unmeasured visual effects.
Research requires public/legitimate artifacts, provenance, hashes and bounded conclusions. No proprietary code, translated decompilation, graphics or secrets. Do not commit .tools, binaries, private captures or user file paths.
Report build limitations honestly. New milestones require owner direction. Remote pushes and releases require authorization. Check AGENTS.md before work.
